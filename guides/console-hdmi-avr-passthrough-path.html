Console → AVR / HDMI feature passthrough

Decide whether the console should go direct to the TV (audio via eARC) or through an audio/video receiver in the HDMI video path. This is not a capture-card guide.

Updated: 2026-09-25

Lead answer: If console → TV already delivers your 4K/high-refresh/VRR target and the TV can send audio back via eARC/ARC, KEEP that direct path. Put the AVR in the video path only when you need AVR HDMI switching or confirmed high-bandwidth passthrough—and then use Ultra High Speed cables on both hops plus the receiver’s enhanced/8K input modes.
Confidence: console HDMI docs + AVR maker enhanced-mode framing • exact receiver matrices vary

1. Play-only / keep-TV + eARC first

Direct TV often wins

PlayStation, Xbox, and other HDMI consoles do not need an AVR to show a picture. Many modern TVs accept high HDMI modes on a game port and return audio over eARC. If that already works: KEEP YOURS—do not insert an AVR “because surround” until you confirm you need AVR video switching or speaker amp topology that requires it.

Capture hardware is still unrelated: viewing never requires a capture card. See the capture guide only if you record/stream.

2. When the AVR is in the video path

Topology

Console HDMI OUT → Ultra High Speed HDMI → AVR HDMI IN → Ultra High Speed HDMI → TV HDMI IN. Audio can stay on the AVR’s speaker outputs; the TV may be used as a display-only sink.

  • Every hop must support the target mode (4K120, VRR, HDR class as needed).
  • A weak cable on either hop breaks features even if the other hop is fine.
  • AVR “HDMI passthrough” / enhanced formats are model- and firmware-specific—verify the maker’s 4K/8K signal-format docs for your receiver.

Enhanced / 8K input modes

AVR makers (for example Denon manuals for 4K/8K Signal Format) describe Standard vs Enhanced vs 8K Enhanced modes that gate high chroma / 4K120 / 8K-class signaling. Enable the mode that matches your console + TV + cable class; if picture fails after enabling Enhanced, fall back per the maker’s troubleshooting—not by inventing a new receiver SKU.

3. Decision tree

  • Picture + TV speakers / eARC already OK? → Direct console→TV. KEEP. Stop.
  • Need AVR speakers + confirmed high HDMI features? → AVR in video path; Ultra High Speed both hops; set enhanced/8K modes; match console display settings.
  • Features work direct but fail with AVR in-line? → Diagnose AVR input mode, firmware, and both cables—compare against the KEEP direct path.
  • Only need to record/stream? → That is capture topology (different guide)—not AVR shopping.

FAQ

Is this a capture guide?

No. AVR / audio video receiver / HDMI feature passthrough for play—not record/stream capture cards.

Should the AVR sit in the video path?

Only when needed. Direct TV + eARC is often valid—KEEP when high modes already work.

Cable class with AVR in-line?

Ultra High Speed on both hops for high modes; enable AVR enhanced/8K formats per maker docs.

Do I need capture to watch TV?

No.
