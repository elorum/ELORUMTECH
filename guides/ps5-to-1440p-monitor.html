PS5 to a 1440p monitor

Does the PS5 output 1440p, and will your monitor’s HDMI input take 1440p at 60 Hz or 120 Hz? That is the question this page answers—not cable shopping in general.

Updated: 2026-10-17

Short answer: yes—PlayStation documents a dedicated 1440p Resolution setting and a Test 1440p Output path for SDR/HDR at 60 Hz and 120 Hz, plus VRR, when the screen supports it. Set Settings → Screen and Video → Video Output → Resolution → 1440p. Whether you get 1440p/120 (and VRR) still depends on the monitor’s HDMI input timings—DisplayPort marketing numbers do not apply. HDMI 2.0 vs HDMI 2.1 is not decided by the label alone: check what that HDMI port actually lists for 2560×1440.

What PlayStation documents for 1440p

Sony’s PS5 resolution guide states that if your TV or monitor supports 1440p output, you can test 1440p for SDR/HDR at 60 Hz / 120 Hz and for VRR. To use 1440p output, set Resolution to 1440p under Video Output. The console also documents a separate 120 Hz Output toggle for displays and games that support 120 Hz.

Source: PlayStation Support — How to change PS5 console resolution (Test 1440p Output / Video Output)

What must match on a 1440p monitor

1. HDMI input timings (not DisplayPort)

The PS5 is HDMI-only. Confirm 2560×1440 (or your target) at the refresh you want on the monitor’s HDMI row. A “165 Hz / 240 Hz” DisplayPort headline does not guarantee the same over HDMI.

2. 1440p at 60 Hz vs 120 Hz

After setting Resolution to 1440p, use PlayStation’s test and the 120 Hz Output option only when the HDMI path offers them. If 120 Hz or VRR fails the test, the monitor HDMI input is the first limit to check—not a new cable by default.

3. HDMI 2.0-class vs HDMI 2.1-class ports

Many 1440p gaming monitors expose different refresh ceilings on HDMI 2.0-class vs HDMI 2.1-class inputs. Buy and configure from the port’s listed 1440p timings and features (VRR, HDR), not from the version string alone.

Cable bandwidth (summary)

For Ultra High Speed HDMI, when 4K/120 needs more bandwidth, and when to keep the cable supplied with the PS5, use the primary cable guide—do not re-decide cable class on this page. See PS5 HDMI 2.1 cable path: Ultra High Speed, 4K/120 and when the supplied cable is enough.

Practical checklist

  • Open the monitor’s HDMI input specs (not only the DisplayPort row).
  • Confirm 2560×1440 at 60 Hz and, if you want it, at 120 Hz over HDMI.
  • On the PS5: Settings → Screen and Video → Video Output → Resolution → 1440p; run Test 1440p Output; enable 120 Hz Output / VRR only if the test and display support them.
  • If the picture mode fails at 120 Hz or VRR, treat the monitor HDMI input as the limit before shopping for a new cable.

Common mistakes

Reading DisplayPort numbers for an HDMI console

A “240 Hz” monitor may only offer that rate over DisplayPort. The PS5 never uses DisplayPort, so HDMI limits decide what you get at 1440p.

Assuming every 1440p panel unlocks 120 Hz on HDMI

Some panels list 1440p/120 only on DisplayPort or only on a specific HDMI port class. Verify the HDMI row, then use PlayStation’s 1440p test.

Exact-model and tool links

  • For a manufacturer-confirmed 4K/120 PS5 pairing on a specific Dell panel (not 1440p), see PS5 → Dell U2725QE: 4K 120Hz HDMI compatibility.
  • If refresh is stuck or you need to see which link limits the mode, use the Display & Connection Solver (console HDMI paths: start from the Console & handheld display hub).

When to keep what you have

Keep the monitor and cable when HDMI already supports your target 1440p refresh and any VRR you care about, and PlayStation’s 1440p test passes. Check the monitor’s HDMI timings and console settings, and change only the part proven to limit your target mode—not the whole stack by default.

FAQ

Will any 1440p monitor work with a PS5?

Most will show a picture over HDMI, but high refresh rates and VRR depend on the monitor’s HDMI input capabilities—not only DisplayPort marketing specs.

Do I need HDMI 2.1 for 1440p on PS5?

It depends on the resolution, refresh rate and features you want. Verify supported timings on the actual HDMI input rather than buying on the version label alone.

Should I replace the cable that came with the PS5?

Usually no. Keep the supplied cable if it already supports your target mode.

Why does DisplayPort refresh look higher than HDMI on my monitor?

Many monitors advertise peak refresh over DisplayPort while offering lower limits on HDMI. The PS5 uses HDMI only.
