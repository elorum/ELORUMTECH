Exact-model compatibility

PlayStation 5 → Dell U2725QE

Verdict · Manufacturer-confirmed

Compatible for 4K up to 120 Hz

Use the PS5 HDMI output directly into the U2725QE HDMI input. PlayStation documents HDMI 2.1 and 4K/120 Hz output. Dell specifies its HDMI input for UHD 3840×2160 at 120 Hz with HDMI 2.1 FRL and VRR.

Best connection path

PS5 HDMI OUT → Ultra High Speed HDMI cable → Dell U2725QE HDMI IN.

Use the cable supplied with the PS5 or another certified Ultra High Speed HDMI cable. A USB-C or Thunderbolt adapter is unnecessary for the direct console-to-monitor path.

120 Hz and VRR

120 Hz must be enabled in PS5 video-output settings and the game must support a 120 Hz mode. PlayStation also supports VRR on compatible HDMI 2.1 displays; Dell lists VRR on this monitor's HDMI 2.1 input.

Practical checklist

  • Connect HDMI OUT on the PS5 to the U2725QE HDMI IN (not DisplayPort or Thunderbolt upstream).
  • In PS5 Settings → Screen and Video, set resolution to 2160p and enable 120 Hz / VRR if available.
  • Confirm the game offers a 120 Hz or Performance mode when that is your goal.
  • Start with the HDMI cable supplied with the PS5 before buying another.

Common mistakes

  • Expecting DisplayPort or Thunderbolt monitor ports to matter for a PS5—they do not; the console is HDMI-only.
  • Assuming every game will run at 120 fps; hardware path capability and game mode are separate.
  • Buying a new HDMI cable when the supplied cable already supports Ultra High Speed bandwidth.
  • Inserting USB-C/HDMI adapters that add failure points without helping this direct path.

Keep yours

If you still have the HDMI cable supplied with the PS5 and it is working correctly, keep it. The connection itself does not justify buying another cable.

FAQ

Can the PS5 run 4K at 120 Hz on the Dell U2725QE?

Yes. PlayStation documents HDMI 2.1 and 4K/120 Hz output; Dell specifies UHD 120 Hz with HDMI 2.1 FRL and VRR on this input.

Do I need a USB-C or Thunderbolt adapter?

No. Use PS5 HDMI OUT directly into the U2725QE HDMI IN.

Should I replace the HDMI cable that came with the PS5?

Keep it if it works. The path does not justify a new cable by default.

Is VRR supported on this pairing?

Yes on the documented hardware path; enable VRR in PS5 settings and confirm per-game support.
